# Workbench 图文与表达形式

v3，2026-10-29；2026-10-30 增补第八篇。先判断内容要解释的关系，再决定是否画图及采用何种形式。前三篇七组双语图、一组双语文字对照表，以及工程规约列表；第八篇当前正文使用概念地图、后台任务与视频处理三组双语图，配合权限、故障处理、运营与阶段顺序四张文字表；原三组工程图随展开稿存档；不要求每篇或每节的图数相同。

| 位置 | 表达形式 | 直接回答的问题与边界 |
| --- | --- | --- |
| Environment：导读后、第一个配置小节前 | `environment-toolkit` 职责分支 | 人定义什么，Agent 组织什么，模型／工具／运行环境／规约各做什么？是全文总览，不是 Node.js / Python 配置图。 |
| Environment：第 4 节工具接入说明后、推荐前 | `environment-mcp` 接入拓扑 | Host 内多个 Client 如何连接对应的 Server，并接入文档、网页和浏览器？三个例子对应后文工具，不暗示必须同时安装。 |
| Environment：第 6 节工程纪律 | 文字规则与执行说明 | 范围、计划与技术约束已用三条列表明确。删除重复流程图，保留原规约和检查要求。 |
| Scope：第 1 节路径导读后 | `scope-paths` 双路径合流 | 已有框架和模糊想法分别怎样开始，最终汇入什么共同问题？两条路径可以互补。 |
| Scope：第 4 节最短完整流程的案例目标后 | `scope-mvp` 连续旅程 | 单次练习最短但完整的价值流程是什么？材料、出题、作答反馈、回顾不可只保留孤立功能；不是所有产品的固定 MVP。 |
| Scope：第 5 节“分开检查功能完成与用户价值” | 可选择的文字对照表 | 对照问题、案例、依据与结论边界。删除两栏卡片图片和重复说明，不把功能通过当成价值成立。 |
| Architecture：第 2 节选型导读后 | `architecture-decisions` 判断与回路 | 从产品约束比较候选，核实关键假设；适配则记录，不适配则修订。不是技术栈排名。 |
| Architecture：第 3 节假设练习案例引入后 | `architecture-boundaries` 可信边界 | 哪些处理必须在可信服务端，谁保存密钥，外部生成结果怎样回到校验？职责边界不代表微服务拆分。 |
| Architecture：第 5 节失败处理说明后 | `architecture-failures` 时序与替代结果 | 同步生成成功与失败分别怎样返回？保留输入、显式重试；超时不等于取消上游工作。 |
| Production：第 1 节全貌导读后 | `production-map` 六分支思维导图 | 从个人 Demo 到共享平台要考虑哪些问题？身份权限、后台任务、响应速度、多人使用、失败恢复和长期运营是关联能力，不是必须依次安装的工具。 |
| Production：第 3 节三个概念后 | `production-task-flow` 后台执行与持久状态拓扑 | 前台接单、队列等待、Worker 执行、数据库状态和文件成果如何配合？网页经服务端查状态，Worker 回写进度；图中连接是职责关系，不要求拆成微服务。 |
| Production：第 4 节介绍字幕与分段后 | `production-video` 有限并行与汇总 | 长视频怎样跳过不必要工作，分段转写并归并成有来源的章节和概览？限制同时处理的片段数，核对时间与全片覆盖，区分部分与完整结果。 |
| Production：第 2、6、7 节概念与决策 | 三张可选择的文字对照表 | 身份/角色/归属分别管什么，故障怎样选择应对，运营日常看什么？每节辅以短解释、加粗要点或步骤，不堆长段落。 |
| Production：第 8 节升级顺序 | 可选择的文字阶段表 | 下一批用户会遇到什么问题，先补哪些能力，用什么结果验收？阶段为示例，基本权限边界不延后。 |
| Production 工程存档：平台骨架、恢复、发布 | `production-boundaries`、`production-recovery`、`production-release` | 保存概念地图重写前的三组工程细节图与引用；清单标记 `article: false`，不再插入当前入门正文。 |

MCP 角色关系沿用 [官方架构说明](https://modelcontextprotocol.io/docs/learn/architecture)。其他案例均为原文的假设设计，不添加实际产品数据、数量和性能结论。

前三篇 2026-10-29 发布核对六份正文的章节、图注、CMS 与公开页面；当时实际视觉巡检受 Work 浏览器设置限制。第八篇 2026-10-30 当前为本地双语正文和六张在用图，另外六张图随工程展开稿存档，不继承前三篇的 CMS 发布状态；浏览器验收与未完成项见对应执行记录。提示词和代码继续保留为可选择文本。
