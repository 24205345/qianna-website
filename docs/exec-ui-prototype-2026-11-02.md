## 写作与设计

顺序为任务 → 信息层次 → 效果描述 → 操作负担 → 等待与恢复 → Mock 原型 → 任务试用。短解释、分点、加粗、表格与图分工，目录标题保持简短。

实验室延续白底、中性灰、衬线标题、无衬线正文。桌面三栏分别选择、体验和描述；中屏和手机采用 CSS 重排。该响应式实现尚未经过本轮真实浏览器视觉验收。

图表实际使用 SmartDiagram 的 Mermaid 清洗器、本站原生 SVG 排版和 sharp WebP 导出。新增图源、SVG、WebP 与清单齐全，中英六张图分别查看；图中没有实测数据或数量暗示。生成前已有三十条清单保留，当前共三十六条。

官方来源通过客户端 HTTP 核对成功：GOV.UK Making prototypes、WCAG 2.2 Quick Reference、MDN prefers-reduced-motion 和 dialog。文章按论点就近链接，未使用研报视频时间戳或夸大的性能结论。
