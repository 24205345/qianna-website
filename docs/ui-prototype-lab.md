## 设计与范围

- 按首页 `FeaturedProjectsSection` 与 `EditorialNotesSection` 的呈现模式采用 stone 浅底、衬线标题、无衬线正文、Sub-rail 分类底线与节制的边界。“认识页面”桌面为完整范例与解释两栏；其他主题为选择、体验、描述三栏。中屏把描述移到体验下方，手机顺序堆叠。
- 五组十七例：“认识页面”帮助区分九个区域；布局组包含网格、工作区与页脚，文字与动效组保留原例，组件组包含行动入口与原八类组件。只运行当前选中的模拟；切换时清除计时器与观察器，并忽略已排队的旧回调。
- 行动入口用同一份材料依次比较笼统文案、明确文案、主次强调。切换时保留材料、校验和结果；生成只显示固定示例题。页脚用同样四个链接比较平铺与分组；链接定位到预览内对应内容并转移焦点，窄屏自然堆叠。
- 五站资源在第四章正文和 Workbench 资源卡按问题给出指引，实验室不重复呈现。示例独立制作，不嵌入或重新分发外部模板、截图或着色器代码。
- 其他主题桌面左侧提供通俗问题与术语目录，中间操作、右侧解释。“认识页面”直接点选范例中的九个区域；中小屏在选中区域内显示解释与需求句，避免点击后反馈留在屏幕外。
- 设置位于预览上方，以可见按钮展示全部选项，保持与原生选择框同步。切换设置仍保留当前答案、草稿和模拟状态；键盘焦点返回当前选项。
- 说明优先给名称、通俗解释与一句可用的需求；场景、变化、边界及完整提示词默认折叠。完整复制包含需求句与详细规则。静态排版不显示动效时长控制；复制失败时展开文本并提供手动复制。中文界面和中文正文的提示词均为中文，英文版本对应英文。
- 描述遵循“对象 → 触发 → 变化 → 结束与边界”。生成文字随具体设置和语言变化；过渡时长与任务执行时长分开。
- 操作方法与资源参考放在正文，实验室直接呈现可操作的示例和对应解释。按钮静态状态快照与默认模式下的实际任务分开解释；折叠面板、标签页和浮层使用相互一致的材料内容。
- 网格标题和导语使用真实栏宽，不用任意字符上限制造折行；排版示例在预览内居中，标题与正文沿同一阅读边线。行长按中英文分别设置，窄屏仍自然换行。
- 手机工作区使用最大 390 px 的有边界、可滚动区域；CSS 容器查询根据实际宽度切换结构，ResizeObserver 报告实际宽高。桌面区域变窄再恢复时重新显示参考材料，不能遗留隐藏状态。
- 同一例切换配置时保留输入、作答、反馈、当前视图和 AI 执行状态；切换示例或离开页面则结束当前模拟。AI 未生成内容即失败／取消时不声称保留了部分结果。
- 独立参考页不显示个人站点顶栏或“阅读第四章”入口。中英文分别由正文和 Workbench 链接的 `lang=zh`／`lang=en` 参数选择，页内没有语言切换按钮；移除顶栏时同时清理其脚本引用与样式。
- 输入只存在于当前页面内存，刷新即清除。原生 `dialog` 用于浮层；键盘焦点、触屏替代、减少动态效果和复制失败回退属于验收范围。
- DOM 测试不能验证实际布局、原生焦点锁定、Esc 或触屏。浏览器不可用时必须单独记录这些缺口。

正文第二节补充视觉说明，第六节提供可点击原型提示词，第七节提供任务验收提示词。中英文各三段 `prompt`；同步器按所在二级章节识别，避免新增前置提示词时把原有资源内容错配。Workbench 分别使用 `prompt-visual-brief`、`prompt-clickable-prototype` 和 `prompt-prototype-review`；发布器维护相同范围，保留其余资源。

视觉说明参考 Anthropic 的前端美学指南，并按现有站点规则改写为知识问答案例。字体名单、背景或字号偏好不构成本站统一禁令；独立实验室本轮没有更换字体、主题或资源版本。

### 作品集实验场（参考用户提供的 TSX）

借鉴 `frontend_prompt_lab.tsx` 的“方案 → 预览 → 术语 → 需求”联动方式，独立实现为无需 React 运行时的本地模块 `studio.js` / `studio.css`。保留本站中性灰、衬线标题、分类横轨和无标签呈现；不照搬附件中的深色应用外壳、霓虹描边、技术栈要求或依赖。

- 三种方案同步版式、字体、圆角、间距和悬停；手动更改后清除方案激活态。
- 桌面／手机控制改变范例容器的实际宽度，容器查询重新排版；预览独立滚动。
- 认图模式维持九区域点选；网页体验模式提供真实筛选、详情弹窗及本地联系反馈，切换样式保留分类。
- 右侧三页签提供部位解释、样式调整与整页需求，支持方向键与 Home / End。整页需求由当前选择生成，尊重减少动态效果；复制失败时选中文本，不报告成功。
- 新增七项行为检查覆盖上述联动、状态保留、焦点返回、双语需求与复制失败。原十七例继续保留。
