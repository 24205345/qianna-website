# 交互实验室初学者呈现改版 · 2026-11-10

原页面直接让读者选择网格、排版和组件，没有先说明页面各区域的名称。对没有网页设计经验的人，体验效果后仍难以说清要修改哪里、具体怎样变化。本轮沿用站点的 stone 中性灰、双字体、Sub-rail 与细边界，调整入门顺序和交互反馈。

## 本地实现

- 默认进入“认识页面”。用一张可点选的阅读页说明九个区域：站点导航、眉标、主标题、导语、页签、侧栏导航、主内容区、辅助面板和页脚；左侧目录和示例中的区域均可选择。
- 选中后同步更新名称、通俗解释、日常说法和需求句。桌面在右侧查看说明；手机在选中的区域内直接展开反馈，隐藏重复的认图目录。
- 原十四例保留，共五组十五例。目录先用“内容怎样分栏”等问题说明用途，再给术语；设置移到预览上方，按钮直接显示可选项。原生 select 保留为同步状态节点，构建出的页面无新增运行依赖。
- 需求句随当前设置、时长和减少动态效果更新；完整规则默认折叠，复制仍包含详细边界。切换样式保留原有答案、输入、反馈与模拟状态。
- 网格、滚动、视图切换示例的 Aa 占位块换成真实材料摘记。示例均在本地内存运行，不上传或调用模型。

源位于 `scripts/ui-prototype-lab/`；新增 `orientation.js`，由 `scripts/build-ui-prototype-lab.mjs` 一起打包到 `public/notes/ui-prototype-ergonomics/interface-lab.html`。

## 验证

- `node --test --test-isolation=none tests/ui-prototype-lab.test.mjs`：27 项行为检查通过，包括原模拟状态、双语九区域联动、设置按钮、答案保留、复制与减少动态效果。
- `node scripts/build-ui-prototype-lab.mjs --check`：源与产物一致。
- `npm run lint`：通过，无错误或警告。
- 真实浏览器：桌面可点选页面区域并联动说明，也可用键盘 Enter 激活目录；分栏选项同步改变预览和需求句。375 px 实际内容宽度下，认图解释在选中位置展开，无页面横向溢出；工作区切换手机预览并展开材料后，已选答案保留。
- 桌面与手机截图保存于本次 Codex 可视化目录。没有把 DOM 替身测试表述为原生 dialog 焦点、系统辅助技术或真实触屏设备的全面验收；本轮没有重做这些完整检查。

Next 开发启动器在受限环境下报 `spawn EPERM`，所以浏览器检查通过 Node 静态 HTTP 服务打开生成的单文件 HTML；本轮未更改 Next 路由或 React/TS 组件。
