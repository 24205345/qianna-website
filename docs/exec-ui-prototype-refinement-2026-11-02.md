# 第四章本地化与交互实验室扩充 · 2026-11-02

## 用户反馈与修改范围

用户指出中文阅读流程中的提示词仍为英文，实验室存在重复说明、视觉语言与个人网站不一致，而且只覆盖组件，缺少页面整体布局、文字排版和动画。

本轮仅增量修改第四章及其配套资源：

- 中文正文两段提示词改为中文；英文保留英文指令与 Workbench 英文资源对应。实验室每个示例、每个设置的复制内容按当前语言生成；按钮模拟状态也改为中文名称。
- 保留原七个章节、三张各语言配图和八类组件。新增六个页面级示例，按布局、文字与排版、页面动效、组件交互分为四组十四例。
- 对照首页 `FeaturedProjectsSection`、`EditorialNotesSection` 及 AGENTS.md 设计规范，采用 stone 浅底、衬线标题、无衬线正文、细边界、分类底线和宽窄屏重排。没有引入深色胶囊按钮、装饰渐变、emoji 或等宽正文。
- 减少重复说明：提示词默认折叠；场景、变化和边界各有一处说明；不需要动画的静态示例隐藏时长控件；复制失败时展开文本供手动操作。

## 六个页面级示例

| 示例 | 实际可调行为 | 关键边界 |
| --- | --- | --- |
| 内容网格 | 主次双栏、等宽双栏、单栏 | 窄屏按阅读顺序合并 |
| 分屏工作区 | 桌面与手机预览、参考材料展开 | 切换后保留作答选项 |
| 文字层级 | 衬线／无衬线标题、字号对比 | 保留正文和注释层次 |
| 阅读节奏 | 行高、段间距、最大行宽 | 用同一份中英文内容比较 |
| 滚动与进入 | 原位淡入或短距离上移、内部固定导航与阅读位置线 | 无观察器或减少动态效果时直接展示；旧回调不得修改新示例 |
| 视图切换 | 原位淡入或上移淡入 | 保留导航和焦点；不声称进行了浏览器路由切换 |

模拟页面、控件与右侧复制文字共同变化。示例参数与真实请求耗时分开，不执行模型调用或持久化。

## 源文件与维护

原单文件 HTML 拆为可编辑源，再构建为自包含发布文件：

- `scripts/ui-prototype-lab/shell.html`：页面结构与必要的静态回退。
- `scripts/ui-prototype-lab/editorial.css`：网站风格、示例与响应式样式。
- `scripts/ui-prototype-lab/lab.js`：语言、导航、原八类交互及复制。
- `scripts/ui-prototype-lab/page-studies.js`：六个页面级示例；导出入口由构建器内联到共享作用域。
- `node scripts/build-ui-prototype-lab.mjs`：生成 `public/notes/ui-prototype-ergonomics/interface-lab.html`；`--check` 检查同步。

`sync-ui-prototype-note.mjs` 增加提示词语言检查；摘要与资源说明由八类扩充为四组十四例。Notes 写作规范明确中文指令放在中文正文、英文指令放在英文正文；产品名、代码与 API 标识保留原文。维护文档和索引同步更新。
