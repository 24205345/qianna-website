## 逐例检查

| 示例 | 发现与处理 | 已有证据／仍需实屏检查 |
| --- | --- | --- |
| 内容网格 | 删除标题 18ch、导语 48ch 的任意上限，使用实际栏宽；空间不足仍自然换行 | 用户截图与源可确认旧问题；不同宽度的新换行需实屏 |
| 分屏工作区 | 完整边界、最大 390 px 手机区域、内部滚动、实际宽高报告；容器查询切换结构 | DOM 验证选项、反馈保留与尺寸回调；真实尺寸、滚动和窄屏需实屏 |
| 文字层级 | 阅读栏居中，标题和正文共用边线；正文提高至 15／17 px，说明同步；不再把正文固定在左半边 | DOM 验证模式与复制参数；字体、行宽与留白需实屏 |
| 阅读节奏 | 整个阅读栏一起居中和调整宽度；中文用 28em／36em，英文用 60ch／72ch，避免混用字宽单位 | DOM 验证配置；实际中英文节奏需实屏 |
| 滚动进入 | 保留首次进入、重播、粘性导航、阅读线与减少动态效果回退；补具体练习 | DOM 验证观察器清理与可见回退；入场效果、滚动区域需实屏 |
| 视图切换 | 改效果时保留当前视图；开启减少动态效果清除当前动画类 | DOM 验证焦点规则与视图保留；动效观感需实屏 |
| 按钮 | 明确静态快照与默认模式真实点击模拟的区别；解释加载快照不会自行结束 | DOM 验证重复激活拦截；真实悬停、按下、焦点需实屏 |
| 卡片 | 维持悬停位移、重播、键盘轮廓与触屏直接激活；练习明确比较两种反馈 | DOM 验证事件；触屏和轮廓裁切需实屏 |
| 输入框 | 更换校验时机保留已填内容和校验状态 | DOM 验证错误、修正、提交与配置切换；触屏键盘需实屏 |
| 标签页 | 以同一案例的实际材料替换空泛说明；维持切换草稿与方向键操作 | DOM 验证草稿和 roving tabindex；实际键盘体验需实屏 |
| 折叠面板 | 明确是“提交后的回顾”，把占位指令替换为解释与原文，避免没有作答却泄露答案的语境冲突 | DOM 验证单开／多开；展开可发现性需实屏 |
| 弹窗与抽屉 | 材料详情加入真实证据内容；保留本地备注、关闭与重新打开 | DOM 只验证应用钩子；原生焦点锁定、Esc、遮罩、窄屏高度未验证 |
| 操作反馈 | 切换就地／浮动模式保留已显示消息；不自动消失，不声称保存服务器记录 | DOM 验证显示、关闭和应用焦点；浮动位置需实屏 |
| AI 结果 | 切换呈现模式保留执行进度；尚无内容时失败／取消不声称保留部分结果；控件禁用后转到可用按钮 | DOM 验证暂停、恢复、失败、重试、取消、模式切换及应用焦点；实际朗读与视觉需实屏 |
